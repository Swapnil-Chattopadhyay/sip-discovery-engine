# SIP Discovery Engine

An interactive research tool for analysing **12-month SIP continuation behaviour** among first-time mutual fund investors on Zerodha Coin.

Built as part of the **NextLeap PM Fellowship — Growth PM Case Study** by Swapnil Chaudhari.

## Live Demo

Deployed via GitHub Pages → [https://swapnil-chattopadhyay.github.io/sip-discovery-engine](https://swapnil-chattopadhyay.github.io/sip-discovery-engine)

## What's inside

- **AMFI industry data** — monthly SIP registration and discontinuation trends (Oct 2024 – Sep 2026)
- **KPI dashboard** — 8 metric blocks covering folios, amounts, and discontinuation rates
- **Interactive AI research agent** — 11 topic areas with evidence status tracking
- **Supplemental evidence integration** — 30+ hand-screened records covering payment friction, mandate failures, penalty anxiety, and cross-surface issues
- **Full source attribution** — every data point linked to its original source

## Context

This engine was built to support a Growth PM case study on improving 12-month SIP continuation for first-time Zerodha Coin investors. The research covers:

- Why first-year investors discontinue SIPs (payment discovery failures, mandate complexity, early return anxiety)
- Behavioural patterns across Active, At-Risk, Lapsed, and Re-engaged investor states
- Product intervention design grounded in real AMFI data
